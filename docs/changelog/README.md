# Changelog archive

[CHANGELOG.md](../../CHANGELOG.md) keeps `[Unreleased]` and the 5 most
recent releases. Everything older lives here, one file per release, and a
file's name never changes once it is written — a link to it does not rot and
`git log` follows it.

Written by `just changelog-rotate`; `just changelog-check` is what notices
the main file has grown past the limit. Do not edit an archived section: the
notes on its GitHub release were rendered from it at publish time, and
editing one makes the two disagree with no way to tell which is right.
